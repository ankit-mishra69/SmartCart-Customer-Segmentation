# SmartCart-Customer-Segmentation
An Unsupervised Machine Learning project that segments retail customers using K-Means clustering for targeted marketing and business insights.

Project Overview:
This project applies Unsupervised Machine Learning techniques to segment retail customers into meaningful groups based on income, spending behavior, and purchase patterns.
The objective is to help businesses improve marketing strategies and customer targeting.
 
Technologies Used:
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-Learn

Machine Learning Concepts Used:
Data Preprocessing
Feature Engineering
Data Scaling (StandardScaler / MinMaxScaler)
K-Means Clustering
Elbow Method
Silhouette Score

Steps Performed:
Data Cleaning
Handling Missing Values
Feature Engineering (Age, Customer Tenure)
Data Normalization
Finding Optimal Clusters (Elbow Method)
Applying K-Means Clustering
Cluster Visualization
Business Insights Extraction

Business Impact:
Identifies high-value customers
Detects low-engagement segments
Helps in targeted marketing
Improves customer retention strategies

📂 Dataset:
Retail customer dataset containing demographic and purchase-related attributes.

Future Improvements:
Deploy as a Web App using Streamlit
Add interactive dashboard
Automate cluster interpretation
Compare with Hierarchical Clustering & DBSCAN
